# Data source

`maternal_health_risk_kurigram.csv` contains 1,205 records of pregnant women collected at General Hospital,
Kurigram, Bangladesh, with 11 features and a binary risk label (High / Low).

Please cite the original authors when using the data:

- M. U. Mojumdar et al., "Maternal health risk factors dataset: Clinical parameters and insights from rural Bangladesh," *Data in Brief*, vol. 59, Art. no. 111363, 2025, doi: 10.1016/j.dib.2025.111363.
- M. U. Mojumdar et al., "Maternal health risk assessment dataset," Mendeley Data, V1, 2024, doi: 10.17632/p5w98dvbbk.1 (licence: CC BY 4.0).

The file is kept exactly as released, including the record with an age of 325, which the cleaning step removes.
